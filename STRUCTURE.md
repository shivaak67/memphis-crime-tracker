# Project structure guide

Internship-style map of folders and files.

## Steps

1. Scaffold folders/files - done (`chore/scaffold-project-structure`)
2. Database blueprint + packages - in progress (`feat/database-schema`)
3. Pull Memphis crime data into our database
4. Build data APIs for map and charts
5. Build the public website UI
6. Deploy online (free/cheap)

## Important folders

- `app/` - the website pages and data endpoints
- `components/` - map, charts, and filters UI pieces
- `lib/` - helpers (database door, city data feed, shared types)
- `drizzle/` - database blueprint (`schema.ts`) and migration history
- `scripts/` - manual tools (like syncing data on your computer)
- `public/` - static images/icons
